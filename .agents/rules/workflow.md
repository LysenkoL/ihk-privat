# Правила рабочего процесса для ihk-sim

- У Claude нет доступа к терминалу и Git — доступ есть только у тебя (Antigravity).
- Команда пользователя **«обнови ...»** / **«обнови все»** означает полный цикл синхронизации и деплоя:
  1. Проверить синтаксис и статус измененных/новых файлов.
  2. При смене версии актуализировать `VERSION` в `sw.js` и зафиксировать в `IDEEN.md`.
  3. Выполнить `git add .`, создать содержательный коммит и сделать `git push origin main`, чтобы GitHub Pages обновился.
